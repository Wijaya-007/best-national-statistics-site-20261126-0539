# StatDesk Indonesia — National Statistics Site

A working national statistics site for Indonesia, built from static files with no network request: real BPS figures with sources and years, seven hash-routed pages (dashboard, population, economy, health, education, regions, about), hand-drawn SVG charts, and working controls — year picker, economy tabs, sortable/searchable province table, and chart/table toggle.

Run it locally with `node serve.ts` (serves `app/` at http://localhost:8080), or hand it in with `MAKEFUN_OUTPUT_DIR=out node main.ts`, which copies `app/` and `screenshots/` to the output directory and writes `dossier.json` via `vendor/makefun-frontend.ts`.
